# 超知能MUSE無料セミナー（muse/）— 超知能活用力診断

パソコン教室用 `survey/` とは混ぜない、超知能MUSE専用の一式です。

## ページ
- `pre.html` … 参加前アンケート。`?date=2026-11-02&kai=第1回`（広告から来た人用は `&src=ad` を足す）
- `index.html` … 終了アンケート。`?date=2026-11-02&kai=第1回`
- `my.html` … 個人ページ「超知能活用力診断」。`?id=M001&k=…`（鍵つきの個人リンクはメールでだけ案内する）
- `kekka.html` … 講師用の集計（合言葉が必要）。参加者ID・同じ回の伸び（参加前→終了）つき
- `Code.gs` / `appsscript.json` … 受け口（Apps Script。タイムゾーン Asia/Tokyo）
- `config.json` … 受け口のURL（`GAS_URL`）

## 流れ
1. 参加前・終了アンケート・UTAGE申込（webhook, `type=apply`）のどれかで初めて来た人に、メールアドレスをキーに参加者番号 `M001`〜 を発行（シート「参加者マスタ」）
2. 回答直後：超知能活用力診断の結果メール（参加者番号・ステップ・物差し6項目・前回比・個人ページのリンク）
3. 毎朝6時台：終了アンケートの翌朝／参加前アンケートは開催前日の朝に、困り事に合わせたプロンプト＋その回の「問いかけの型」を1人1通で送る
   - 型のローテーションは `KATA_ROTATION`、困り事→型は `TROUBLE_KATA`（Code.gs の定数）

## 立ち上げ（1回だけ）
1. MUSE専用スプレッドシートに `Code.gs` と `appsscript.json` を入れる（clasp push か、Apps Script に貼り付け）
2. ウェブアプリとしてデプロイ（実行：自分／アクセス：全員）→ `/exec` のURLを `config.json` に入れて push
3. 関数 `setup` を1回実行 → Google の許可 → 合言葉・個人リンク用の秘密の文字列・毎朝6時のトリガーができ、合言葉が自分宛てにメールで届く
   - 合言葉と秘密の文字列は「スクリプト プロパティ」に入る。このリポジトリ（公開）には書かない

## 流入経路（広告分析）
- `attr.js` が、最初に来たときの `utm_source / utm_medium / utm_campaign / utm_content / utm_term`・広告クリックID（fbclid / gclid / yclid / LINE）・参照元ドメインを端末に覚え、回答と一緒に送る
- 参加者マスタには「最初に来たときの値」を残す（後から上書きしない）。回答ごとの値と回答にかかった秒数は各シートに残る
- 広告のリンク例：`pre.html?date=2026-11-02&kai=第1回&utm_source=meta&utm_medium=paid&utm_campaign=muse1&utm_content=動画A`
- 集計ページの「流入経路」で、経路・キャンペーン・広告ごとに「申込 → 参加前 → 終了1回以上 → 3回以上」を数える

## テストと後片付け
- テストはメールアドレスに `+musetest` を含める（例：自分のアドレスの `+musetest1`）。番号は `T001`〜 になり、本番の番号を使わない
- 消すときは Apps Script で `deleteTestData` を実行（`+musetest` の行と `T` の番号を全シートから消す）

## 運用メモ
- 物差し設問（ステージ0〜10／物差し6項目）は参加前・終了で同一。途中で文言を変えると前回比較が崩れるので変えない
- MailApp は1日100通まで（無料のGoogleアカウント）。残りが5通以下になると、その日の送信を止め、翌朝6時に回す
