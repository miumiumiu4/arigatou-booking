# 超知能MUSE無料セミナー 終了アンケート（muse/）

パソコン教室用 `survey/` とは混ぜない、超知能MUSE専用のアンケート一式です。仕組みは survey/ と同じ型です。

## 構成
- `index.html` … 回答ページ。URLパラメータ `?date=2026-11-02&kai=第1回` で回を指定（無ければ今日＋第1回）
- `kekka.html` … 集計・分析ページ（合言葉が必要）。回の集計（到達率・ステージ分布・物差し・困り事ランキング）と、個人の前回比較（同じメールアドレスで連結）
- `Code.gs` … 受け口（Apps Script）。回答をスプレッドシート「回答」へ保存し、翌朝6時台に困り事別の実践プロンプトを自動送信する
- `config.json` … 受け口のURL（デプロイ後に GAS_URL を入れる。空の間、回答は回答者の端末に保存され、開き直すと自動再送される）

## 立ち上げ手順（公開前に1回だけ）
1. 回答用のスプレッドシートを新規作成（MUSE専用。パソコン教室のシートとは分ける）
2. 拡張機能 → Apps Script に `Code.gs` の中身を貼る
3. `READ_KEY` を本物の合言葉に書き換える（集計ページの読み取り用）
4. デプロイ → 新しいデプロイ → ウェブアプリ（実行：自分／アクセス：全員）→ 発行された `/exec` のURLを `config.json` の `GAS_URL` に入れて push
5. Apps Script で `authorize` を1回実行（メール送信の権限許可）
6. Apps Script で `setupMorningTrigger` を1回実行（毎朝6時台の自動送信トリガー）
7. 次回予告の文は `Code.gs` の `NEXT_TEASER` を書き換える（保存だけで反映、再デプロイ不要）

## 運用メモ
- アンケートは各回必須で、回答が到達確認を兼ねる（答えた人から順次解散）
- 物差し設問（ステージ0〜10／できる度6項目）は第1回と第5回で同一。途中で文言を変えると前回比較が崩れるので変えない
- 個人の成長はメールアドレスで連結する。参加者には「毎回同じアドレスで」と案内する
